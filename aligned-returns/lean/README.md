# Lean 4 sources for paper 2

Built against Mathlib with Lean 4 v4.34.0; both are pinned by `lean-toolchain` and `lake-manifest.json`.

```bash
lake exe cache get
lake build
```

`lake exe cache get` downloads Mathlib's prebuilt files, so only the files in `W4lean/` are compiled.

| file | contents |
| --- | --- |
| `Unit2BFormalR1.lean` | the model and the thirteen statements of the certificate layer, stated with `sorry` |
| `Unit2BFormalR1Proofs.lean` | their proofs: `Phi_antitone`, the floor conditions, `cover_sound`, the bracket and identity (8) |
| `Unit2BFormalR1R2.lean` | generated: the thirteen statements with their proofs inlined, no `sorry` |
| `Unit2BKappaStatementR1.lean` | the statement of the reduction, Theorem 1 |
| `Unit2BKappaProofsR10.lean` | the complete proof of Theorem 1, `kappa_reduction`, ported from a separate Lean project |
| `Unit2BKappaProofsR1.lean` to `Unit2BKappaProofsR9.lean` | lemmas from an earlier, staged attempt at the same proof; R10 does not import them, and the axiom audit covers them |
| `KappaIndDefsR10.lean`, `Unit2BKappaDefEqR10.lean` | that project's model definitions, and kernel proofs by `rfl` that they equal this project's |
| `TypeIdCheckKappaR10.lean` | kernel check that the ported theorems have exactly the types of the statements |
| `ChiSquaredSpikeR1.lean`, `ProductMarginalR1.lean`, `OrthonormalCoordsR1.lean`, `ParsevalR1.lean` | Gaussian and chi-square lemmas the proof uses |
| `Unit2BSizeConsR11.lean`, `Unit2BSizeConsAsmR11.lean`, `Unit2BSizeR11.lean` | the size bounds: the constant (19), Theorem 3 and Theorem 6 |
| `StatementIdentityR2.lean` | kernel check that the statements in `Unit2BFormalR1R2.lean` are those of `Unit2BFormalR1.lean` |
| `Unit2BFormalNonvacR1.lean` | witnesses that the hypotheses of the size bound can be met |
| `UnitPReduction.lean` | the paired reduction, Theorem 7 |
| `AxAll.lean` | generated by `../formal01_ax_all.py`: one `#print axioms` per theorem and lemma in the proof files |

Every public declaration in the proof files depends only on `propext`, `Classical.choice` and `Quot.sound`; `../formal01_ax_all.py` checks this and writes the result to `../deposits/ax_all_claims.txt`.
